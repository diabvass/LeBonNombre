# Le Bon Nombre

Petit jeu web où il faut deviner un nombre secret entre 1 et 100.

Développé sur mobile avec Acode + Termux.

### Comment jouer
1. Entrez un nombre entre 1 et 100
2. Cliquez sur Tester
3. Le jeu vous dit si c'est trop grand ou trop petit
4. Abandonnez génère un nouveau nombre
5. Rejouer après une victoire

### Fonctionnalités
- Validation d'entrée (vide, hors intervalle)
- Compteur d'essais
- Indication visuelle rouge / vert
- Sauvegarde du meilleur record en `localStorage`
- Affichage du record en haut de page

### Tech
- HTML / CSS inline / JavaScript vanilla
- 2 fichiers : `index.html` et `serveur.js`
- Aucune dépendance

### Lancer
Ouvrir `index.html` dans un navigateur ou via Acode > Run.
